Vocabulary flashcards
---------------------

.. flashcards:: Animation words
   :id: y10mm-anim-vocab
   :shuffle:

   # Basics
   Frame | One still picture in an animation
   Frame rate | How many frames are shown each second, measured in fps
   Delay | How long one frame is shown in a GIF
   Loop | When an animation goes back to the start and plays again
   GIF | Graphics Interchange Format: an image file that can hold animation and up to 256 colours
   Beta movement | Seeing one object move when still pictures are shown quickly in different places
   Phi phenomenon | Seeing a sweeping sense of motion, with no clear object, when lights flash very fast
   Persistence of vision | An old, outdated idea that pictures linger on the eye; the brain actually calculates motion

   # Making animation
   Keyframe | An important frame that marks the start or end of a movement
   Tween | A frame in between two keyframes, short for in-between
   Storyboard | A set of sketches that plans what happens, like a comic strip
   Layer | A separate part of a Photoshop picture, like a clear plastic sheet
   Timeline | The Photoshop panel used to build animation frames
   Opacity | How see-through a layer is, from 0% (invisible) to 100% (solid)

   # Telling a story
   Opening | The start of a story, which sets the scene and introduces the character
   Development | The middle of a story, where something happens and builds up
   Climax | The biggest, most exciting moment of the story
   Closure | The end of a story, where the problem is solved or the message is shown
   Cause and effect | One event makes the next one happen
   Symbolic code | Something in the picture that stands for an idea or feeling, such as colour or a prop
   Written code | Words in the picture, such as a slogan or call to action

   # Shots and angles
   Extreme long shot (ELS) | Shows the whole setting; often used to open a story
   Close-up (CU) | A face or one object fills the frame; shows feelings
   Low angle | Camera looks up; character seems big or powerful
   High angle | Camera looks down; character seems small or weak
   Pan | The view slides sideways across a scene
   Fade | The picture slowly appears from or disappears to black or white

   # Exporting
   Dither | Mixing dots of colour to fake colours that are not in the palette
   Transparency | Areas of an image that are see-through
   Save for Web | The Photoshop window used to export GIFs
   PSD | Photoshop's own file type, which keeps layers and frames

Mixed quiz
----------

Each time you start, you get 10 questions picked at random.

.. mcqgroup::
   :show-instant-feedback:
   :shuffle-questions:
   :num-questions: 10

   .. multichoice::

      A GIF has 8 frames and every frame has a delay of 0.25 seconds. How long does it last?

      [ ] 0.25 seconds | That is one frame.
      [ ] 8.25 seconds | You added. Multiply instead.
      [x] 2 seconds | Yes. 8 × 0.25 = 2.
      [ ] 32 seconds | Check your maths: 8 × 0.25.

   .. multichoice::

      Which principle makes a character crouch before jumping?

      [x] Anticipation | Correct.
      [ ] Arcs | Arcs are curved paths.
      [ ] Timing | Timing is about the number of frames.
      [ ] Staging | Staging is about presenting the action clearly.

   .. multichoice::

      Which file keeps your Photoshop layers so you can edit later?

      [x] PSD | Correct.
      [ ] GIF | GIFs only keep the finished frames.
      [ ] JPG | JPGs flatten everything into one layer.
      [ ] MP4 | That is a video file.

   .. multichoice::

      What does Photoshop's Tween command **not** change?

      [ ] Position | It can tween position.
      [ ] Opacity | It can tween opacity.
      [ ] Layer effects | It can tween effects.
      [x] The shape of a drawing | Correct. Shape changes need separate layers.

   .. multichoice::

      Hair keeps moving after a character stops running. This is...

      [x] follow through | Correct.
      [ ] anticipation | Anticipation comes before an action.
      [ ] squash and stretch | Not quite.
      [ ] secondary action | Close, but this is follow through.

   .. multichoice::

      Which animation type traces over real video frame by frame?

      [ ] Stop motion | Stop motion photographs real objects.
      [x] Rotoscoping | Correct.
      [ ] Cut-out | Cut-out moves flat shapes.
      [ ] CGI | CGI uses 3D models.

   .. multichoice::

      What is the job of a storyboard?

      [x] To plan the animation with sketches before you make it | Correct.
      [ ] To list the file sizes | No.
      [ ] To store the frames | That is the Timeline.
      [ ] To give credits | That goes in your reflection.

   .. multichoice::

      A 2 second animation at 12 fps needs how many frames?

      [ ] 6 | You divided.
      [ ] 14 | You added.
      [x] 24 | Correct. 12 × 2 = 24.
      [ ] 12 | That is only 1 second.

   .. multichoice::

      Which setting can make a GIF smaller? (Choose **all** that are correct.)

      [x] Fewer colours | Correct.
      [x] Smaller width and height | Correct.
      [x] Fewer frames | Correct.
      [ ] More dither | Dither makes files bigger.

   .. multichoice::

      Which part of a story sets the scene and shows who it is about?

      [x] Opening | Correct.
      [ ] Climax | The climax is the biggest moment.
      [ ] Closure | The closure is the end.
      [ ] Development | The development is where things build up.

   .. multichoice::

      Which shot would best show how a character feels?

      [ ] Extreme long shot | The character is too small to see their face.
      [ ] Long shot | Shows the whole body, but the face is small.
      [x] Close-up | Correct.
      [ ] Bird's-eye view | This is an angle from above.

   .. multichoice::

      A camera looks up at a character. How does the character seem?

      [x] Big and powerful | Correct. This is a low angle.
      [ ] Small and weak | That is a high angle.
      [ ] Far away | That is a long shot.
      [ ] Normal and fair | That is eye level.

   .. multichoice::

      Which is a **symbolic** code?

      [ ] A zoom | A zoom is a technical code.
      [ ] The slogan "Visit us" | Words are written codes.
      [x] A dark, stormy sky | Correct. It suggests danger or sadness.
      [ ] A cut | A cut is a technical code.

   .. multichoice::

      Which early device spins a disc with a different picture on each side?

      [x] Thaumatrope | Correct.
      [ ] Zoetrope | A zoetrope is a spinning drum.
      [ ] Flip book | A flip book has many pages.
      [ ] Praxinoscope | A praxinoscope uses mirrors.

   .. multichoice::

      Most living things move along...

      [x] arcs | Correct.
      [ ] straight lines | Machines move in straight lines.
      [ ] zig-zags | No.
      [ ] circles | Not usually.

   .. multichoice::

      In a frame animation, how do you change a layer in **every** frame at once?

      [x] Select all frames first, then change the layer | Correct.
      [ ] Change it in frame 1 only | That only changes frame 1 for visibility and position.
      [ ] Export the GIF again | No.
      [ ] Use Reverse Frames | That changes the order.
