=======================
Unit 2: Graphic design
=======================

Graphic design is about using pictures, colour and words to send a message. In
this unit you will learn the rules designers use, practise them in Photoshop,
and then design social media content for a client.

.. admonition:: Assessment task

   **Social media content** (media production). You will design a set of posts for
   a client from a design brief. See :doc:`gd_07_social_media_assessment`.

Four-week plan
--------------

.. list-table::
   :header-rows: 1
   :widths: 12 44 44

   * - Week
     - Learn
     - Make
   * - 1
     - :doc:`gd_01_elements_principles` and :doc:`gd_02_colour`
     - Poster critique; colour palette for a brand
   * - 2
     - :doc:`gd_03_typography` and :doc:`gd_04_images_copyright`
     - Font pairing; find and credit Creative Commons images
   * - 3
     - :doc:`gd_05_social_post_tutorial` and :doc:`gd_06_photo_editing`
     - Event post in Photoshop; photo fixes
   * - 4
     - :doc:`gd_07_social_media_assessment`
     - Finish posts, mock-ups and reflection
